Keyboard layout: Corne + Lily58

Both keyboards use exactly the same layout (from config/layout.dtsi). The Lily58 also has a number row (the dotted top row). Thumb names are under each thumb key: L3 L2 L1 | R1 R2 R3, counted from the middle outward (the Lily58's extra outer thumb keys L4 / R4 are unused).

Rule: hold any thumb and ⌘ ⌥ ⇧ ⌃ are under that same hand.
Hold R1Hold R1 (space): mods under the right hand, the left hand types letters.
Hold L1Hold L1 (backspace): mods under the left hand, the right hand types letters. L1 + A = Caps Lock.
Hold L2Hold L2: arrows on the right, mods under the left hand.
Hold R2Hold R2: mouse on the left, clicks on L1/L2/L3, mods under the right hand.
Hold R3Hold R3: numbers on the left home row, F1-F6 above, mods under the right hand.
Hold L3Hold L3: numbers on the right home row, F7-F12 above, mods under the left hand.
Hold L1 + L2 (or R1 + R2)Hold L1+L2 or R1+R2: MacBook media row on the F1-F12 keys, Bluetooth, bootloader.

thumb you hold ⌘ ⌥ ⇧ ⌃ grey = types the normal key Combos (plain typing, after a short pause): S+D esc · D+F tab · J+K ⏎ · K+L ⌫ · L+; ⌦

Set up a Mac (once)

1. Flash both keyboards

  1. GitHub → Actions → the latest run → download firmware.
  2. For each half: plug it in by USB, double-tap its reset button, and drag the matching file (corne_left…uf2 / corne_right…uf2, or lily58_left… / lily58_right…) onto the drive that appears.
  3. If you ever saved changes in ZMK Studio: open Studio and click Restore Stock Settings. Otherwise the keyboard keeps the old layout.

2. Turn on the Fn key (Karabiner)

Holding C or , sends F18. Karabiner turns F18 into the Mac's real Fn / 🌐 key, so 🌐+F (full screen), Fn+← (Home), window tiling, emoji and dictation all work. ZMK can't send a real Fn by itself: a Mac only accepts Fn from Apple-made keyboards.

  1. The karabiner/ folder in this repo is Karabiner's settings folder. On a new Mac, link it once:
    mv ~/.config/karabiner ~/.config/karabiner.old; ln -s ~/projects/Mano-zmk/karabiner ~/.config/karabiner
  2. Karabiner-Elements → Settings → Devices: the keyboard shown as Corne or Lily58 (maker "ZMK Project") must have Modify events switched on. The repo's config switches it on; check it once.
  3. Test: open Karabiner-EventViewer and hold C. You should see fn. Then try 🌐+F in any window.
  4. F1–F12 on the keyboards stay real F-keys (the config says so for these keyboards). For media keys, hold L1+L2 or R1+R2.
  5. On a Mac without this Karabiner config, holding C or , does nothing extra; tapping still types c and ,.

3. Choose what a single tap of Fn does

System Settings → Keyboard → Press 🌐 key to (on this Mac: Change Input Source). Pick Show Emoji & Symbols or Start Dictation if you prefer.
